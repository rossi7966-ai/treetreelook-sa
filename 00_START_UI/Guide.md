# UI 人類操作指南

## 你只做三件事

1. **拍決策**:G0 會送來「開畫前決策清單」(哪些 TBD 必須先決);你裁,AI 動工
2. **看截圖**:wire 線框是灰階素描——沒有色彩風格干擾,你直接感受操作流程與資訊架構;主行動有粗框、未決處有斜紋佔位,一眼看出「誰是主角、哪裡還沒定」
3. **排議題**:審查發現進議題帳(UIX-###),你定優先序;修沒修好看帳,不用翻報告

## 三閘門(每閘=機器檢核全綠+判斷審查無 🔴)

```
SA 規格 → [G0 規格就緒] → 線框(wire) → [G1 結構定案] → 上 token 樣式 → [G2 樣式合規] → 交付開發
              ↑拍決策            ↑看截圖                        ↑看樣式截圖
```

- 結構沒吵完(G1)不上妝;妝(G2)只准用 token,手寫數值機器會抓(列舉樣式內;樣式外歸 R 層+selftest 持續補洞)
- 機械判斷交腳本(UIV 檢核,清冊=.metaui/UI_KIT/checks/README.md),AI 只做需要判斷的事——檢核結果是真實 stdout,不是 AI 的印象

## 快速開始

1. 專案 repo 已含本部署內容(`.metaui/` + `00_START_UI/`);尚未部署見下節「部署動作」
2. 對 AI 說 Playbook 的卡 U0 指令句,從規格就緒檢核開始
3. 各情境操作見 `Playbook.md`;AI 行為守則見 `.metaui/UI_KIT/AI_Rules.md`
4. **同事(非拍板者)的入口=`SOP.md`**:開工句/收工/准駁/還原點一頁講完,
   零先備知識可用;AI 須承接其對同事之字面承諾(行為端錨定=AI_Rules 引用鏈通則)

## 部署動作(把本包裝進專案;三步)

1. **複製**:`UI_DEPLOY/` 內容整包複製至專案 repo 根(整包成根,外殼消失)。
2. **路由檔**:專案根建立/更新 `CLAUDE.md` 與 `AGENTS.md`(雙檔同文=公共路由檔)。
   最先部署之包=建檔(標準檔頭+自家一行);後到之包=只添自家一行,
   禁改他包行、禁入守則字面。標準字面(家族定案單一源)如下;
   建檔時僅列已部署包之行,全家對照表供後到抄行:

   ```markdown
   # 專案代理入口(公共路由檔)
   > 本檔=專案根公共財,僅路由禁守則字面;由最先部署之包建立,後續各包自添一行,不改他包行。
   依當前任務角色,先完整閱讀對應守則再動工:
   | 角色 | 守則單一源 |
   |------|-----------|
   | 系統分析(SA) | `.metasa/SA_KIT/AI_Rules.md` |
   | 介面設計(UI) | `.metaui/UI_KIT/AI_Rules.md` |
   | 系統設計(SD) | `.metasd/SD_KIT/AI_Rules.md` |
   | 程式開發(PG) | `RUNNER_RULES.md` |
   | 提案寫作(PT) | `.metapt/PT_KIT/AI_Rules.md` |
   ```

3. **版次戳**:部署來源(發佈架 tag/commit)記入 `00_Status.md` 交接日誌部署列。

## 前提

- MetaSA 產出已就位(DesignSpecs 的 W 節點/L2/L3/L4)——UI 流程消費 SA 規格,不替代它
- 導覽主軸需有 DEC 決策(00_Glossary 區塊B);沒有就先拍一條,AI 會停下來要
