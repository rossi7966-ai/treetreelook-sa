## 🟨1. 故事背景(Story)
- **As a** 系統管理員(Role 2)
- **I want** 打開單筆紀錄看到完整時間、帳號、角色、IP、裝置與異動內容
- **So that** 能判斷該操作是否合理並作為佐證

## 🟦2. 業務規則(Rules)
- **Rule 1**:功能可用性與資料範圍同 W03 Rule 1、Rule 2。
  > 🔗 **相依性宣告**:[W03](./M07-F01-W03_查詢登入登出紀錄.md)。
- **Rule 2**:基本資料顯示完整時間(至秒)、姓名、使用者帳號、角色、組織、IP、裝置;登入登出紀錄另顯示事件與系統端。
  > 🔗 **相依性宣告**:[W01](./M07-F01-W01_記錄進出組織事件.md) Rule 4、[W02](./M07-F01-W02_記錄模組操作事件.md) Rule 2。
- **Rule 3**:操作紀錄另顯示模組 / 功能、動作、操作對象與異動內容——修改為「欄位 / 修改前 / 修改後」對照;新增為新增後資料;刪除為刪除前快照;查詢為查詢條件。權限異動加提示。
  > 🔗 **相依性宣告**:W02 Rule 3、Rule 4。
- **Rule 4**:切換事件不顯示另一端組織,並說明原因。
  > 🔗 **相依性宣告**:DEC-013。
- **Rule 5**:唯讀,無修改 / 刪除操作;開啟詳情即記一筆查詢(R)。
  > 🔗 **相依性宣告**:DEC-015;W02 Rule 5。

## 🟩3. 具體實例與測試資料(Examples / BDD Scenarios)
### Scenario:[正常路徑] 檢視權限異動詳情
- **Given** 操作紀錄列表有一筆「帳號管理 / 帳號 / 修改 / test_team_leader」
- **When** 點[詳情]
- **Then** 側欄顯示完整時間、操作者姓名與帳號、角色、組織 OID 1、IP
- **And** 異動內容表列「角色:廠商組員 → 廠商組長」「廠商群組(GID):— → 樹花園」,並提示此異動會改變資料範圍

### Scenario:[邊界] 檢視切換離開
- **When** 於登入登出紀錄點一筆「切換離開」的[詳情]
- **Then** 顯示「為維持組織隔離,不顯示切換的另一端是哪個組織」
