## 🟨1. 故事背景(Story)
- **As a** 系統管理員(Role 2)
- **I want** 依日期、姓名、事件、系統端篩選本組織的進出紀錄
- **So that** 能確認某段時間內誰進出過本組織

## 🟦2. 業務規則(Rules)
- **Rule 1**:功能可用性——僅當前 OID 下 `Role=2` 可使用;`Role=1` 母帳號不開放;其餘角色不開放。
  > 🔗 **相依性宣告**:DEC-015、DEC-022。母帳號目前無產生機制、預計廢棄,不另做功能層排除;DEC-011「母帳號全開」之衝突實務上不發生。
- **Rule 2**:資料範圍——僅當前 OID 的紀錄;切換組織後即改為新 OID 的紀錄。
  > 🔗 **相依性宣告**:DEC-013;`02_Scope.md` L1。
- **Rule 3**:篩選條件為時間區間(今天 / 近 7 天 / 近 30 天 / 自訂,預設近 7 天)、姓名或帳號、事件(進入組織 / 切換離開 / 切換進入 / 登出)、系統端。
  > 🔗 **相依性宣告**:[W01](./M07-F01-W01_記錄進出組織事件.md) Rule 1(事件值域)。
- **Rule 4**:列表欄位為日期、姓名、事件、系統端、詳情入口;依時間新到舊排序。
  > 🔗 **相依性宣告**:DEC-015;詳情見 [W05](./M07-F01-W05_檢視紀錄詳情.md)。
- **Rule 5**:查詢本身不記錄。
  > 🔗 **相依性宣告**:DEC-022。

## 🟩3. 具體實例與測試資料(Examples / BDD Scenarios)
### Scenario:[正常路徑] 查近 7 天的進出紀錄
- **Given** tpark3 以系統管理員身分在 OID 1
- **When** 開啟[系統管理 / 登入登出紀錄],保留預設近 7 天並按[查詢]
- **Then** 列表只顯示 OID 1 的紀錄,欄位為日期、姓名、事件、系統端
- **And** 本次查詢不新增任何紀錄

### Scenario:[權限] 同帳號跨組織不可見
- **Given** tpark3 在 OID 1、OID 2 皆為系統管理員,且 OID 2 有林冠廷的進入組織紀錄
- **When** tpark3 在 OID 1 以姓名「林冠廷」查詢
- **Then** 顯示「這個條件下沒有紀錄」

### Scenario:[權限] 非系統管理員
- **Given** tpark3 於「森樂社區」(OID 3)為廠商組員
- **When** 切換至 OID 3 並開啟登入登出紀錄
- **Then** 顯示整頁無權限提示,不顯示任何紀錄

## 🎨4. 元件動態狀態(L1 Components State)
- `LoginLogTable`:[Default] 近 7 天結果 / [Empty] 「這個條件下沒有紀錄。試著放寬時間區間或清除篩選。」
- `AccessDenied`:[Shown] 「你在這個組織沒有查看紀錄的權限」+ 當前角色說明
