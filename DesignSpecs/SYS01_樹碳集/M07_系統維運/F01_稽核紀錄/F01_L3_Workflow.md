# F01業務流程拓樸

## 業務流程映射表
> 唯一授權來源:`06_HandoffPackage.md` §9.1

**Epic:EP12-系統維運與稽核(M07-F01 稽核紀錄段)**
- 旅程起點:任一使用者在某 OID 內進入 / 離開組織,或於任一模組執行新增、查詢、修改、刪除
- 旅程終點:該 OID 的 `Role=2` 系統管理員能在本組織範圍內追查「誰、哪天、對什麼、做了什麼」,並可帶出紀錄佐證
- 主線:`[M07-F01-W02] -> [M07-F01-W04] -> [M07-F01-W05]`
- 分支:
  - `[M07-F01-W01] -> [M07-F01-W03] -> [M07-F01-W05]`
  - `[M07-F01-W04] --{條件:需帶出紀錄}--> [M07-F01-W06]`
  - `[M07-F01-W03] --{條件:需帶出紀錄}--> [M07-F01-W06]`
  - `[M07-F01-W06] --{條件:篩選結果超過單次上限}--> [M07-F01-W04]`(W03 同理)
  - `[M07-F01-W03] / [W04] / [W05] / [W06] --{條件:查閱稽核紀錄本身即為查詢}--> [M07-F01-W02]`
- 終止:
  - `[M07-F01-W01] --{條件:帳號驗證層事件,發生於選組織前}--> [M07-F01-W99]`(跨系統 SYS02-SS03)
  - `[M07-F01-W03] / [W04] --{條件:當前 OID 下角色非 Role=2}--> [M07-F01-W99]`
