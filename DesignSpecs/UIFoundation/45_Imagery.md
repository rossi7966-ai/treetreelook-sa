# 圖像與插畫規範

> 白話:圖像必須有真實使用者需求才放(GOV.UK 節制原則)——空狀態要指路、
> 首頁要秒懂今天、資料要一眼可辨。裝飾性圖庫照片一張都不放;
> 但該有圖的位置留白，頁面就永遠是半成品。本章管「哪裡該有圖、
> 什麼形式、資產沒到位之前怎麼辦」。

## 一、圖像三分法

| 形式 | 何時用 | 何時不用 |
|------|--------|---------|
| **icon** | 現象/操作/狀態的即時辨識(40_Iconography 管) | 需要情感或情境敘事時 |
| **插畫** | 空狀態指路、導引說明、首頁主視覺情境 | 呈現真實資料/實景時 |
| **照片** | 實景資料(測站、田區、災害實況)佐證;hero 氛圍背景(§五 條件) | 內容區裝飾(禁 stock 充內容) |

判準一句話:拿掉這張圖，使用者會不會少知道一件事?會=功能性圖像，放;
不會=裝飾，不放。

## 二、插槽規格

- 比例 token 綁定(tokens.json `imagery` 群組):

| token | 值 | 用途 |
|-------|-----|------|
| `--imagery-ratio-hero` | 21 / 9 | 首頁主視覺帶(content-width 1120 下高約 480) |
| `--imagery-ratio-card` | 16 / 9 | 卡片封面圖 |
| `--imagery-ratio-media` | 4 / 3 | 內文媒體圖 |
| `--imagery-ratio-square` | 1 / 1 | 頭像、縮圖 |
| `--imagery-empty-max-h` | 240px | 空狀態插畫高度上限 |
| `--imagery-ph-min-h` | 160px | 佔位槽最小高度 |

- 裁切紀律:`object-fit: cover` 為預設;主體資訊(人臉、測站本體、警戒區)不得被裁，
  必要時改 `contain`+`band-soft` 底。
- 防版面跳動:圖像槽一律先佔面積(aspect-ratio 或 min-height)，載入不推擠內容。

## 三、佔位契約(placeholder)

資產未到位時，插槽以「標示型佔位」補位——佔位=結構完整性的宣告，非缺件。
版型先定，資產後補不動版。

- class 契約:`<div class="ph-slot" data-ph="槽名" data-ratio="21/9">`。
- 視覺規格(`assets/placeholder.css`，吃 tokens):`band-soft` 底+`divider` 虛線框+
  槽名與比例標註文字(`placeholder` 色)。
- 禁隨機圖床/示意假圖:佔位就誠實長得像佔位，不得以無關圖片充版面。
- 佔位槽數量與位置屬 G1 結構審範圍;實資產到位後移除 `ph-slot` class 換實件。

## 四、插畫風格

- 平塗色塊(flat)，禁寫實漸層堆疊、禁擬真材質。
- 限用 tokens 色板(primitive 全集內取色;主色系優先，警戒色不入插畫)。
- **避免可愛風**(2026-08-19 設計師裁定):不用擬人化、圓臉大眼、玩具比例;
  走幾何、扁平、工具感——本站受眾=機關專業人員，親和靠色彩與留白，不靠賣萌。
- 風格個性(筆觸、圓角、比例)=設計師裁量;上句裁定內，起始資產可由 code 端
  以 SVG 產出，設計師握風格否決權，正式版是否重繪由設計師決定。

## 五、攝影使用(二類，門檻不同)

- **內容照**:呈現真實資料脈絡(測站、田區、觀測設備、災害實況)——僅實景照，
  來源與授權逐張登記(`assets/README.md` 授權清單;首張實照入包時建授權簿)。
- **hero 氛圍照**(2026-08-19 增，案源=設計師回饋):首頁主視覺背景可用
  免授權金圖庫(如 Unsplash)，條件四項:
  ①主題與服務語境相符(農業地景、天空氣象;禁假人物擺拍與無關場景)
  ②必壓品牌色罩，文字對比依 hero-text 驗算過 AA
  ③來源、攝影者、授權逐張登記，頁面標註來源
  ④圖庫照=可用起始資產，自有或委製照片到位時優先替換。
- 內容區禁裝飾性 stock 照片(GOV.UK 同則:誤導感+維護債);氛圍照僅限 hero 帶。

## 六、alt 紀律(掛 30_UXWriting)

- 承載資訊的圖:alt=內容+目的(「嘉義測站雨量分布圖，顯示本週累積 120 毫米」)，
  不寫「圖片」「照片」開頭。
- 裝飾性(理論上不該存在，過渡期若有)=`alt=""`。
- 載入失敗退場:alt 文字顯示於 `band-soft` 底，不留破圖。

## 七、檢核掛載

- V:「圖像槽佔位完備」=候選檢核(頁面 hero/圖像槽=實資產或合規 `ph-slot`，
  二擇一，零空槽;checks/README 候選登記，立案權=Trainer);UIV-05 涵蓋佔位樣式 hardcode。
- R:三分法判準與插畫風格=G1/G2 判讀項。

## Known Gaps

- 實資產包候設計師定向後填充(現行全佔位);插畫風格個性未定。
- 攝影授權簿未建(首張實照時建)。
