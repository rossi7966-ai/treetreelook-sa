# 視覺層級與版面結構 參考指南

## CRAP 四大原則

### 對比（Contrast）
- 標題 vs 內文：字級差距建議至少 1.5x（例如 Body 16px，H2 24px）
- 粗細差距：主要標題使用 700，輔助文字使用 400，避免全版面同一字重
- 色彩對比：主要行動按鈕（CTA）顏色與背景應有明顯區隔，不可與次要元素相同

### 重複（Repetition）
- 同類按鈕（Primary / Secondary / Destructive）必須在整個介面中保持一致形狀與顏色
- 圖示風格統一（Outlined / Filled 不可混用）
- 卡片、清單等重複性元件的內部結構應一致（標題位置、操作按鈕位置）

### 對齊（Alignment）
- 所有元素應有明確的對齊基準線（左對齊、置中、右對齊），避免隨意偏移
- 表單欄位、標籤、說明文字應共用對齊軸
- 多欄版面各欄起始點應整齊對應

### 親密性（Proximity）
- 相關元素之間的間距應小於不相關元素的間距（例如：標題與其段落間距 < 段落與下一段標題間距）
- 表單 label 應緊鄰對應的輸入欄位
- 按鈕群組之間的間距應小於按鈕群組與其他區塊的間距

## 完形原則（Gestalt Principles）

### 相似性（Similarity）
- 同功能元素（如所有「刪除」按鈕）應使用相同的視覺語言
- 不同功能的元素若視覺過於相似，會造成使用者誤判操作意圖

### 連續性（Continuity）
- 視線應能沿著版面元素的排列方向自然流動，不被突兀的元素打斷
- 水平或垂直的元素排列優於斜角或不規則排列

### 圖地關係（Figure/Ground）
- 前景內容（文字、按鈕、圖示）與背景應有足夠色彩或明度差異
- 浮層（Modal、Dropdown、Tooltip）應透過陰影或遮罩明確與底層內容區隔

### 封閉性（Closure）
- 卡片、區塊即使沒有完整邊框，也應能透過背景色、陰影或間距被識別為獨立單元
- 省略號（…）或截斷文字應讓使用者清楚感知「還有更多內容」

## 視線動線

### F-Pattern（適用於資訊密度高的頁面，如列表、文章）
- 第一橫掃：頁面頂部橫向（Logo、導覽列、主標題）
- 第二橫掃：內容區上半段（副標題、第一段文字）
- 垂直掃描：左側縱向（列表項目首字、縮圖）
- 重要資訊、CTA 應集中於這三個區域

### Z-Pattern（適用於資訊量少的頁面，如 Landing Page）
- 視線從左上 → 右上 → 左下 → 右下 依 Z 字形移動
- CTA 按鈕通常放在右下角（Z 字終點）

### CTA 位置原則
- 主要行動按鈕應置於視線終點或視覺重心
- 避免將 CTA 埋在頁面中段或被其他元素遮蔽

## 空白運用（White Space）

### 微觀留白（Micro White Space）
- 文字行距（line-height）建議 1.4～1.6 倍字級
- 圖示與文字之間應有固定間距（建議 4px～8px）
- 按鈕內部 padding 左右應大於上下（例如：水平 16px、垂直 8px）

### 巨觀留白（Macro White Space）
- 頁面區塊之間應有足夠分隔（建議至少 48px～80px）
- 內容區域與螢幕邊緣應保留頁邊距（建議桌機 ≥ 24px，手機 ≥ 16px）

### 留白意圖判斷
- 留白應引導視線流向下一個元素，而非讓使用者感到迷失
- 若某區域留白過大且無視覺引導，需確認是否為設計失誤而非刻意排版

## 字級比例（Typographic Scale）

### Modular Scale 建議比例
| 比例 | 名稱 | 適用場景 |
|------|------|---------|
| 1.067x | Minor Second | 資訊密度高、空間有限 |
| 1.125x | Major Second | 一般資料型介面 |
| 1.25x | Major Third | 通用 Web 應用 |
| 1.333x | Perfect Fourth | 行銷頁、Landing Page |
| 1.5x | Perfect Fifth | 大標題導向的視覺設計 |

### 各層級基準（以 Body 16px、比例 1.25x 為例）
| 層級 | 計算值 | 建議取整 |
|------|--------|---------|
| Body | 16px | 16px |
| H3 | 16 × 1.25 = 20px | 20px |
| H2 | 20 × 1.25 = 25px | 24px |
| H1 | 25 × 1.25 = 31.25px | 32px |

### 審查要點
- 同一層級的文字是否在整個介面中使用一致的字級
- 相鄰層級之間的字級差距是否足以讓使用者感知層級差異（差距過小會造成視覺層級模糊）
- 字級數值是否符合 Figma/程式碼中定義的 typography token
